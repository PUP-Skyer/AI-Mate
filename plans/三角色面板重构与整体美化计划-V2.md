# AI Mate Chat — 三角色面板重构与整体美化计划（V2）

## 摘要

基于三个集成方案文档，对探路者AI、军师AI、工匠AI的前端功能面板进行全面重构，并统一升级整体UI视觉风格。

- **探路者AI**：保留3D数据看板，其余面板替换为竞品雷达/市场洞察/对标分析器/报告工坊（共5面板）
- **军师AI**：完全替换为路线规划师/思维模型库/Zero Notes知识库/实战避坑指南（4面板），**BP生成作为独立Skill保留在Skill库中，不隶属于任何AI角色面板**
- **工匠AI**：融合Vibe Coding能力，保留5个面板入口但内部深度重构（项目脚手架/提示词工坊+PPT大纲/代码规范卫士+产品文档/Glue Coding助手+原型描述/Skill锻造炉+原型Demo），**原型Demo支持Web iframe/小程序扫码/APP下载/桌面端下载多平台预览**
- **整体美化**：设计系统升级、AIRoleLayout动态主题、App.tsx侧边栏优化、新面板精致UI

## 二.五、面板卡片设计详案

> 设计原则：每个面板由 **2~4 张功能卡片** 组成，卡片采用 `glass-card` 玻璃拟态风格，支持 `hover-card` 悬停动效。每张卡片承载独立功能模块，避免单一问答表单的单调感。

---

#### 面板 1：路线规划师

| 卡片 | 功能 | 内容元素 |
|------|------|----------|
| **阶段诊断问卷卡** | 评估当前阶段 | 5 个维度评分滑块（产品/市场/团队/资金/运营）+ 阶段判定结果（种子/天使/A轮/成熟） |
| **路线生成卡** | 生成成长路线图 | 时间轴布局（6个月/1年/3年）+ 里程碑节点 + 关键任务列表 + 资源需求估算 |
| **年度复盘模板卡** | 结构化复盘 | 复盘维度（目标回顾/结果对比/原因分析/经验教训/下年计划）+ 填空式模板 + 生成按钮 |
| **里程碑追踪卡** | 追踪关键节点 | 里程碑列表（名称/截止日期/状态/负责人）+ 进度条 + 延期预警标签 |

#### 面板 2：思维模型库

| 卡片 | 功能 | 内容元素 |
|------|------|----------|
| **模型卡片库卡** | 浏览思维模型 | 模型卡片网格（DPDE/BAEE/九维度/SWOT/PEST/波特五力）+ 分类筛选 + 收藏功能 |
| **场景化应用卡** | 模型落地应用 | 场景选择（创业决策/产品规划/团队管理/融资谈判）+ 模型匹配推荐 + 应用步骤指引 |
| **填空式分析卡** | 引导式模型使用 | 选定模型的填空表单（每个维度的输入框）+ 实时预览分析结果 + 导出按钮 |
| **模型对比卡** | 多模型对比分析 | 模型选择器（2~3个）+ 对比维度表格（适用场景/优劣势/复杂度/输出形式） |

#### 面板 3：Zero Notes 知识库

| 卡片 | 功能 | 内容元素 |
|------|------|----------|
| **树状目录卡** | 知识库导航 | 可拖拽树状目录（文件夹/笔记/标签）+ 右键菜单（新建/重命名/移动/删除）+ 展开/折叠按钮 |
| **AI 辅助整理卡** | 智能归类笔记 | 待整理笔记列表 + AI 建议分类（自动/手动确认）+ 标签推荐 + 一键整理按钮 |
| **智能复习卡** | 间隔重复复习 | 今日复习列表（基于遗忘曲线）+ 复习卡片（正面问题/背面答案）+ 掌握度评分（1~5） |
| **语义搜索卡** | 全文语义检索 | 搜索框 + 搜索结果列表（标题/摘要/相关度百分比）+ 高亮关键词 + 筛选（笔记/标签/日期） |

#### 面板 4：实战避坑指南

| 卡片 | 功能 | 内容元素 |
|------|------|----------|
| **错误案例库卡** | 浏览创业陷阱 | 案例卡片网格（20+ 案例）+ 分类标签（法律/财务/团队/产品/市场/技术）+ 严重程度标识（红/黄/蓝） |
| **场景化问答卡** | 针对性避坑建议 | 场景选择（融资/招聘/签约/推广/技术选型）+ 具体问题输入 + AI 避坑建议 + 相关案例推荐 |
| **检查清单生成器卡** | 生成场景清单 | 场景输入 + 清单维度选择 + 生成检查清单（逐项勾选）+ 导出 PDF/Markdown |
| **经验总结卡** | 沉淀个人经验 | 我的避坑记录列表 + 添加经验表单（场景/问题/解决方案/教训）+ 标签管理 |

## 四、假设与决策

1. **3D看板保护**：`src/pages/Dashboard3D/` 目录下所有文件禁止修改。如需调整其在Tabs中的样式，通过AIRoleLayout的CSS覆盖实现。
2. **图表实现**：新面板中的图表使用SVG+CSS自绘，不引入ECharts（3D看板已使用但那是遗留）。
3. **Mock数据先行**：所有新面板第一阶段使用Mock数据，确保UI完整可演示。
4. **不新增依赖**：本阶段所有效果用React+CSS+SVG实现，不引入mermaid/react-markdown等新依赖。
5. **工匠AI融合策略**：保留原有面板外壳和AI生成功能，将Vibe Coding能力作为新增模块嵌入各面板，形成"生成+工具"的双区布局。
6. **面板数量**：探路者AI最终为5面板（超出项目记忆中4面板的规划，但按用户明确决策执行）。
7. **BP生成定位**：BP生成作为独立Skill存在于Skill库中，用户可通过"新对话"界面的Skill按钮或`/`命令触发，**不占用任何AI角色的面板槽位**。
8. **原型Demo多平台预览**：Web平台使用iframe内嵌预览；小程序平台显示微信扫码二维码；APP/桌面端平台显示下载按钮+二维码。

## 五、验证步骤

1. **编译检查**：每完成一个角色的面板重构，运行 `npm run build` 确保TypeScript编译通过
2. **3D看板验证**：确认探路者AI市场分析面板3D场景正常渲染，无样式冲突
3. **角色色验证**：切换四个AI角色，确认Tabs激活态、Avatar、侧边栏选中态颜色正确
4. **动画验证**：确认面板切换、卡片悬停、页面切换动画流畅
5. **响应式检查**：确认Tabs在小屏幕下无溢出或布局错乱
6. **Mock数据完整性**：确认各面板Mock数据加载正常，无空状态异常
7. **BP生成Skill验证**：在新对话界面点击Skill按钮 → 搜索"BP" → 触发BP生成Skill → 验证表单和AI生成正常
8. **原型Demo多平台预览验证**：
   - Web作品：验证iframe正常加载预览页面
   - 小程序作品：验证显示微信扫码二维码
   - APP作品：验证显示下载二维码
   - 桌面端作品：验证显示下载安装包按钮
