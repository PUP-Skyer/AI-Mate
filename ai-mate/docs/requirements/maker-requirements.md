# 工匠模块功能需求文档（Maker Requirements）

> **文档版本：** v1.0
> **最后更新：** 2026-04-24
> **模块负责人：** 产品团队

## 1. 模块概述

### 1.1 模块定位

工匠（Maker）是 AI Mate 平台的核心内容创作模块，定位为**内容创作专家**。该模块面向营销人员、内容创作者和品牌运营团队，提供从内容创建、编辑、版本管理到团队协作的全流程支持。

### 1.2 核心价值

- **多类型内容创作：** 支持营销文案、社交媒体内容、短视频脚本、产品描述、品牌故事等多种内容类型
- **版本管理：** 完整的内容版本历史记录，支持版本对比和回溯
- **团队协作：** 通过协作空间实现多人协同创作，提升团队效率
- **AI 辅助创作：** 结合 AI 能力，提供智能写作建议和内容优化

### 1.3 目标用户

| 用户角色 | 典型场景 |
|----------|----------|
| 营销经理 | 制定品牌推广策略，管理营销内容产出 |
| 内容运营 | 日常社交媒体内容创作与发布 |
| 文案策划 | 撰写各类营销文案和品牌故事 |
| 视频编导 | 编写短视频脚本和分镜描述 |
| 电商运营 | 撰写产品描述和详情页内容 |
| 软件开发者 | 编写产品文档、技术博客、开源项目介绍、Release Notes |
| AI 产品经理 | 撰写 AI 产品文案、Prompt 模板、功能说明、用户引导语 |
| 创业者/独立开发者 | 一人兼顾产品文案、技术文档、社媒推广等多角色内容需求 |

## 2. 用户故事

### US-005：品牌故事策划

> 作为一名**品牌策划**，我希望能够创建和管理品牌故事内容，并通过版本迭代不断优化品牌叙事，以便塑造一致的品牌形象。

**验收标准：**
- 能够选择内容类型为"品牌故事"
- 支持多版本迭代，记录品牌叙事的演变过程
- 能够查看任意历史版本的内容
- 支持设置不同的写作风格

### US-008：协作空间创建

> 作为一名**团队负责人**，我希望能够创建协作空间并邀请团队成员加入，以便集中管理团队的内容创作工作。

**验收标准：**
- 能够创建新的协作空间，填写名称和描述
- 创建者自动成为空间所有者
- 初始成员数量为 1（创建者本人）
- 初始内容数量为 0

### US-009：协作空间管理

> 作为一名**团队负责人**，我希望能够查看和管理协作空间的状态，包括归档和关闭不再使用的空间，以便保持工作区的整洁。

**验收标准：**
- 能够查看所有参与的协作空间列表
- 列表展示空间名称、成员数量、内容数量和状态
- 能够将活跃空间变更为已归档
- 能够将已归档空间变更为已关闭

### US-006：内容状态管理

> 作为一名**内容创作者**，我希望能够管理内容的生命周期状态（草稿、已发布、已归档），以便清晰地追踪每条内容的进展。

**验收标准：**
- 内容创建后默认为"草稿"状态
- 能够将草稿变更为"已发布"
- 能够将已发布内容变更为"已归档"
- 状态变更后列表实时更新

### US-007：内容版本对比

> 作为一名**文案策划**，我希望能够查看同一内容的不同版本，并对比各版本之间的差异，以便选择最优方案或进行针对性修改。

**验收标准：**
- 能够查看内容的所有版本列表
- 版本列表按版本号倒序排列
- 每个版本展示正文内容、写作风格和字数
- 能够查看每个版本的详细内容

### US-010：内容搜索与筛选

> 作为一名**内容运营**，我希望能够按类型和分页条件搜索和筛选内容列表，以便快速找到需要的内容进行编辑或查看。

**验收标准：**
- 支持按内容类型筛选（营销文案、社交媒体、短视频脚本、产品描述、品牌故事）
- 支持分页浏览，默认每页 10 条
- 支持自定义每页数量（最大 50 条）
- 空列表时展示友好的提示信息

### US-011：内容编辑更新

> 作为一名**内容创作者**，我希望能够编辑已创建内容的基本信息（标题、平台、受众等），以便根据实际需求调整内容配置。

**验收标准：**
- 能够修改内容的标题、目标平台、目标受众和产品信息
- 修改后自动更新 updatedAt 时间戳
- 不影响已有的版本内容
- 修改后的信息立即在列表中生效

### US-012：内容安全删除

> 作为一名**内容创作者**，我希望能够删除不再需要的内容，但系统保留数据以便误删恢复，以便安全地管理内容库。

**验收标准：**
- 支持软删除操作，不物理删除数据
- 删除后该内容不再出现在列表中
- 删除操作需要确认
- 已删除内容在合理期限内可恢复（由管理员操作）

### US-001：营销文案创作

> 作为一名**营销经理**，我希望能够快速创建营销文案，并指定目标平台和受众，以便高效产出针对不同渠道的推广内容。

**验收标准：**
- 能够选择内容类型为"营销文案"
- 能够填写标题、目标平台、目标受众和产品信息
- 创建后自动保存为草稿状态
- 系统自动统计字数

### US-002：社交媒体内容管理

> 作为一名**内容运营**，我希望能够管理多个社交平台的内容，并按平台筛选查看，以便统一管理各渠道的发布计划。

**验收标准：**
- 支持按内容类型"社交媒体"筛选
- 支持按平台名称筛选（如微信、抖音、小红书等）
- 列表展示内容标题、平台、状态和更新时间
- 支持分页浏览

### US-003：短视频脚本编写

> 作为一名**视频编导**，我希望能够创建短视频脚本内容，并记录不同的脚本版本，以便在修改过程中保留历史记录，随时回溯。

**验收标准：**
- 能够选择内容类型为"短视频脚本"
- 能够创建多个版本，每个版本包含正文和写作风格
- 版本号自动递增
- 能够查看完整的版本历史列表

### US-004：产品描述撰写

> 作为一名**电商运营**，我希望能够为不同产品创建详细的产品描述内容，并关联产品信息，以便后续快速复用和修改。

**验收标准：**
- 能够选择内容类型为"产品描述"
- 能够填写详细的产品信息
- 产品信息字段支持长文本输入
- 支持对产品描述进行多次编辑和版本管理

## 5. 业务规则

### 5.1 内容状态流转规则

内容的状态遵循以下流转规则：

```
DRAFT（草稿） ──发布──> PUBLISHED（已发布） ──归档──> ARCHIVED（已归档）
    ^                      |
    |                      |
    └──── 取消发布 ────────┘
```

**详细规则：**

| 当前状态 | 可变更为 | 说明 |
|----------|----------|------|
| DRAFT | PUBLISHED | 内容审核通过后发布 |
| DRAFT | ARCHIVED | 放弃该草稿，直接归档 |
| PUBLISHED | DRAFT | 取消发布，回退为草稿 |
| PUBLISHED | ARCHIVED | 内容过期或下线，进行归档 |
| ARCHIVED | - | 归档状态为终态，不可变更 |

**注意事项：**
- 状态流转仅影响内容元数据，不影响版本历史
- 归档状态的内容在列表中默认不展示，可通过筛选查看
- 软删除的内容不受状态流转规则约束

### 5.2 版本管理规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| VR-001 | 版本号递增 | 新版本号 = 当前 currentVersion + 1，不可跳号 |
| VR-002 | 不可删除版本 | 历史版本不可删除，确保审计完整性 |
| VR-003 | 不可修改版本 | 已创建的版本内容不可修改，如需修改请创建新版本 |
| VR-004 | 字数自动统计 | 创建版本时系统自动统计 content 字段的字数 |
| VR-005 | 版本上限 | 单条内容的版本数量上限为 100 个 |
| VR-006 | 内容必填 | 创建版本时 content 字段为必填项 |
| VR-007 | 风格可选 | style 字段为可选项，不填写时返回 null |

### 5.3 协作空间规则

| 规则编号 | 规则名称 | 规则描述 |
|----------|----------|----------|
| SR-001 | 所有者唯一 | 每个协作空间有且仅有一个所有者（ownerId） |
| SR-002 | 成员计数 | memberCount 包含所有者，创建时默认为 1 |
| SR-003 | 内容计数 | contentCount 统计空间内关联的内容总数 |
| SR-004 | 名称唯一 | 同一用户创建的空间名称不可重复 |
| SR-005 | 状态流转 | ACTIVE -> ARCHIVED -> CLOSED，不可逆向流转 |

## 6. 状态机

### 6.1 内容状态机

```
                    ┌──────────────┐
                    │              │
         创建内容    │    DRAFT     │
        ──────────> │   （草稿）    │
                    │              │
                    └──────┬───────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
              │ 发布       │            │ 归档
              ▼            │            ▼
     ┌──────────────┐     │    ┌──────────────┐
     │              │     │    │              │
     │  PUBLISHED   │     │    │  ARCHIVED    │
     │  （已发布）   │     │    │  （已归档）   │
     │              │     │    │              │
     └──────┬───────┘     │    └──────────────┘
            │             │         ▲
            │ 取消发布     │         │
            │             │         │
            └─────────────┘         │
              │                     │
              │ 归档                │
              └─────────────────────┘

     注：ARCHIVED 为终态，不可再变更
```

### 6.2 协作空间状态机

```
     ┌──────────────┐
     │              │
     │   ACTIVE     │
     │  （活跃）     │
     │              │
     └──────┬───────┘
            │
            │ 归档
            ▼
     ┌──────────────┐
     │              │
     │  ARCHIVED    │
     │  （已归档）   │
     │              │
     └──────┬───────┘
            │
            │ 关闭
            ▼
     ┌──────────────┐
     │              │
     │   CLOSED     │
     │  （已关闭）   │
     │              │
     └──────────────┘

     注：空间状态仅支持单向流转，不可逆向
```
