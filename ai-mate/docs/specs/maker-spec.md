## 1. 角色定位

### 1.1 角色概述

工匠AI（Maker）是 AI Mate 平台中的**内容创作专家**，专注于为企业和个人用户提供高质量的创意内容生成与协同编辑服务。作为平台的核心生产力工具，工匠AI 深度理解中文语境下的营销规律、社交传播逻辑和品牌叙事方法，帮助用户以极低的门槛产出专业级内容。

### 1.2 目标用户

| 用户类型 | 典型画像 | 核心诉求 |
|---------|---------|---------|
| **中小企业主** | 电商店铺运营者、本地生活服务商家 | 快速生成营销文案、产品描述，降低内容制作成本 |
| **内容创作者** | 自媒体博主、短视频创作者、KOL/KOC | 高效产出多平台适配内容，保持更新频率 |
| **品牌营销团队** | 企业市场部、品牌代理公司 | 品牌叙事策划、多渠道内容统一管理 |
| **电商运营** | 淘宝/京东/拼多多运营人员 | SEO 优化产品描述、广告文案批量生成 |
| **个人用户** | 有内容创作需求的普通用户 | 获取灵感、快速生成社交媒体内容 |

### 1.3 核心价值主张

- **效率提升**: 将传统数小时甚至数天的内容创作流程压缩至分钟级别
- **质量保障**: 基于 AI 深度学习模型，产出符合专业标准的内容
- **多平台适配**: 一键生成适配不同平台的内容格式和风格
- **协同共创**: 支持团队协作空间，实现内容创作流程化管理
- **版本迭代**: 完整的版本管理体系，支持内容持续优化

### 1.4 与其他 AI 角色的关系

工匠AI 在 AI Mate 平台中与管家AI（Butler）、顾问AI（Advisor）形成互补关系：

- **工匠AI** 负责「内容生产」环节，产出营销文案、社媒内容、视频脚本等
- **管家AI** 负责「客户服务」环节，处理用户反馈、售后咨询等
- **顾问AI** 负责「战略决策」环节，提供数据分析、市场洞察等

三者通过统一的用户体系和数据中台实现无缝协作。

## 2. 核心功能

### 2.1 营销文案创作

#### 功能描述

支持多种类型、多种风格的营销文案 AI 生成，覆盖广告投放、产品页面、宣传册等核心营销场景。

#### 支持的文案类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| **广告文案** | 短平快的广告标题与正文 | 信息流广告、搜索广告、户外广告 |
| **产品页文案** | 结构化的产品介绍与卖点提炼 | 电商详情页、产品官网 |
| **宣传册文案** | 图文并茂的品牌宣传内容 | 线下宣传册、品牌手册 |
| **活动文案** | 营销活动主题与规则描述 | 促销活动、品牌活动 |
| **邮件营销文案** | 个性化邮件标题与正文 | EDM 营销、客户触达 |

#### 支持的文案风格

- **专业严谨**: 适合 B2B、金融、医疗等行业
- **活泼有趣**: 适合快消品、年轻化品牌
- **温情走心**: 适合母婴、家居、教育等领域
- **高端大气**: 适合奢侈品、高端服务业
- **接地气**: 适合本地生活、下沉市场

#### 功能特性

- 用户输入产品/品牌信息后，AI 自动分析并生成多套文案方案
- 支持指定字数范围（50字以内 / 100-200字 / 200-500字 / 500字以上）
- 支持关键词注入，确保核心卖点在文案中突出呈现
- 提供文案评分功能，从吸引力、可读性、转化力三个维度打分

### 2.2 社交媒体内容

#### 功能描述

根据不同社交媒体平台的内容生态和用户偏好，自动生成平台适配的原创内容。

#### 平台适配策略

| 平台 | 内容形式 | 字数建议 | 风格特点 | 特殊要求 |
|------|---------|---------|---------|---------|
| **微信公众号** | 长图文 | 1500-3000字 | 深度、专业 | 需要标题+摘要+正文结构 |
| **小红书** | 图文笔记 | 300-800字 | 种草、真实体验 | 需要话题标签、表情符号 |
| **抖音** | 短视频文案 | 50-200字 | 爆款、情绪化 | 需要配合话题挑战 |
| **微博** | 微博正文 | 100-300字 | 热点、互动性强 | 需要话题标签、@相关账号 |
| **知乎** | 回答/文章 | 500-2000字 | 专业、有深度 | 需要逻辑清晰、数据支撑 |

#### 功能特性

- **热点融入**: 自动抓取当前平台热门话题，融入内容创作
- **发布时间建议**: 基于平台用户活跃时间数据，推荐最佳发布时段
- **话题标签推荐**: 根据内容语义自动推荐相关热门话题标签
- **内容日历**: 支持批量生成一周/一月的社交媒体内容排期

### 2.3 短视频脚本

#### 功能描述

提供结构化的短视频脚本创作服务，输出包含场景描述、人物对话、字幕文本、背景音乐建议的完整脚本。

#### 脚本结构

```
短视频脚本标准结构:
├── 基本信息（标题、时长、主题、目标平台）
├── 场景列表
│   ├── 场景1: [场景描述] + [画面指示] + [人物动作]
│   │   ├── 对话/旁白文本
│   │   ├── 字幕文本
│   │   └── BGM/音效建议
│   ├── 场景2: ...
│   └── 场景N: ...
├── 整体BGM建议
└── 后期制作备注
```

#### 支持的视频类型

- **产品种草视频**: 突出产品卖点和使用体验
- **品牌故事视频**: 讲述品牌理念和发展历程
- **教程/科普视频**: 步骤化教学内容
- **情感共鸣视频**: 以情感打动目标受众
- **热点蹭量视频**: 结合当下热点创作内容

#### 功能特性

- 支持 15秒 / 30秒 / 60秒 / 3分钟 / 5分钟 等多种时长规格
- 提供分镜建议，帮助用户可视化视频结构
- 自动计算各场景时长分配，确保总时长符合要求
- 支持脚本导出为 PDF 格式，方便团队共享

### 2.4 产品描述撰写

#### 功能描述

为电商平台生成 SEO 优化的产品描述，提升商品搜索排名和转化率。

#### 生成内容包含

- **SEO 标题**: 融合核心关键词，符合搜索引擎优化规则
- **产品卖点提炼**: 从用户视角提炼 3-5 个核心卖点
- **详细描述**: 结构化的产品介绍，包含功能、参数、使用场景
- **关键词布局**: 在标题、描述、卖点中合理分布目标关键词
- **长尾关键词推荐**: 基于行业数据推荐高转化长尾关键词

#### SEO 优化策略

- 关键词密度控制在 2%-5% 之间
- 标题控制在 30 个汉字以内，核心关键词前置
- 卖点使用结构化列表，便于搜索引擎抓取
- 自动检测并避免关键词堆砌

#### 功能特性

- 支持批量生成：一次输入多个产品信息，批量输出描述
- 竞品分析：输入竞品链接，AI 分析竞品描述策略并给出差异化建议
- 多语言支持：中文为主，支持生成英文产品描述（跨境电商场景）

### 2.5 品牌故事策划

#### 功能描述

帮助企业构建完整的品牌叙事框架，从品牌起源、核心理念到未来愿景，打造有温度、有深度的品牌故事。

#### 品牌叙事框架

```
品牌故事策划框架:
├── 品牌定位声明（一句话定义品牌）
├── 品牌起源故事
│   ├── 创始人故事
│   ├── 品牌创立契机
│   └── 早期发展历程
├── 品牌核心理念
│   ├── 使命（Mission）
│   ├── 愿景（Vision）
│   └── 价值观（Values）
├── 品牌人格化
│   ├── 品牌性格特征
│   ├── 品牌语调指南
│   └── 品牌与用户的关系定位
├── 品牌里程碑
│   └── 关键事件时间线
└── 品牌未来愿景
    └── 3-5年发展规划叙事
```

#### 功能特性

- 提供多种品牌叙事模板（创业故事、匠心精神、科技赋能、人文关怀等）
- 支持品牌故事的多版本迭代，逐步打磨完善
- 自动生成品牌故事在不同渠道的适配版本（官网、社交媒体、宣传册等）
- 品牌一致性检查：确保所有内容符合品牌调性

## 3. 用户交互流程

### 3.1 内容生成主流程

```
用户操作流程:
┌─────────────────────────────────────────────────────────────┐
│  步骤1: 用户选择内容类型                                      │
│  ├── 营销文案 / 社交媒体 / 短视频脚本 / 产品描述 / 品牌故事    │
│  └── 选择后进入对应的输入表单                                  │
├─────────────────────────────────────────────────────────────┤
│  步骤2: 填写创作需求                                         │
│  ├── 基础信息: 标题、行业、品牌/产品名称                       │
│  ├── 详细描述: 产品特点、目标受众、核心卖点                     │
│  ├── 风格偏好: 选择文案风格和语调                              │
│  └── 高级选项: 字数范围、关键词、参考素材                      │
├─────────────────────────────────────────────────────────────┤
│  步骤3: AI 生成内容                                          │
│  ├── 系统调用 AI 模型进行内容生成                              │
│  ├── 生成过程中展示进度动画                                    │
│  └── 生成完成后展示结果（通常 2-3 套方案）                     │
├─────────────────────────────────────────────────────────────┤
│  步骤4: 预览与编辑                                           │
│  ├── 用户浏览 AI 生成的内容方案                               │
│  ├── 可选择某套方案进行深度编辑                                │
│  ├── 使用富文本编辑器修改内容                                  │
│  └── 可随时请求 AI 重新生成或局部优化                          │
├─────────────────────────────────────────────────────────────┤
│  步骤5: 保存与版本管理                                        │
│  ├── 保存内容，自动创建版本记录                                │
│  ├── 可添加版本备注（如"优化了开头段落"）                      │
│  └── 支持查看历史版本对比                                     │
├─────────────────────────────────────────────────────────────┤
│  步骤6: 导出与分享                                           │
│  ├── 导出为 Markdown / PDF / Word 格式                       │
│  ├── 复制到剪贴板（一键复制）                                  │
│  └── 分享至协作空间或直接发布                                  │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 协作空间流程

```
团队协作流程:
┌─────────────────────────────────────────────────────────────┐
│  步骤1: 创建协作空间                                         │
│  ├── 填写空间名称和描述                                       │
│  ├── 设置空间可见性（公开/私密）                               │
│  └── 邀请团队成员加入                                         │
├─────────────────────────────────────────────────────────────┤
│  步骤2: 创建内容任务                                         │
│  ├── 指定任务标题和详细需求                                   │
│  ├── 分配负责人和截止日期                                     │
│  ├── 设置优先级（高/中/低）                                   │
│  └── 关联产品/品牌信息                                       │
├─────────────────────────────────────────────────────────────┤
│  步骤3: 协同创作                                             │
│  ├── 负责人使用 AI 生成初稿                                   │
│  ├── 团队成员在线协作编辑                                     │
│  ├── 实时评论和反馈                                           │
│  └── 版本迭代管理                                             │
├─────────────────────────────────────────────────────────────┤
│  步骤4: 审核与发布                                           │
│  ├── 提交审核（状态变更为"待审核"）                            │
│  ├── 审核人审核通过或退回修改                                  │
│  ├── 审核通过后标记为"已发布"                                  │
│  └── 内容归档，留档备查                                       │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 内容状态流转

```
内容状态机:

  [草稿] ──保存──> [已保存] ──提交审核──> [待审核]
    │                  │                      │
    │                  │              ┌───────┴───────┐
    │                  │              │               │
    │                  │         [审核通过]      [审核退回]
    │                  │              │               │
    │                  │              v               │
    │                  │         [已发布] ────────> [已保存]
    │                  │              │
    │                  │              v
    │                  │         [已归档]
    │                  │
    └──────继续编辑─────┘
```

## 5. 数据模型

### 5.1 ContentPiece（内容实体）

存储用户创作的核心内容信息。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `id` | string (UUID) | 是 | 内容唯一标识，自动生成 |
| `userId` | string (UUID) | 是 | 创建者用户ID |
| `title` | string | 是 | 内容标题，最大长度200字符 |
| `type` | enum | 是 | 内容类型：`marketing_copy` / `social_media` / `video_script` / `product_description` / `brand_story` |
| `platform` | string | 否 | 目标平台：`wechat` / `xiaohongshu` / `douyin` / `weibo` / `zhihu` / `ecommerce` / `general` |
| `targetAudience` | string | 否 | 目标受众描述 |
| `productInfo` | JSON | 否 | 关联产品信息（名称、分类、卖点、价格区间等） |
| `currentVersion` | integer | 是 | 当前版本号，默认为1 |
| `status` | enum | 是 | 内容状态：`draft` / `saved` / `review_pending` / `approved` / `published` / `archived` |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 是 | 最后更新时间 |

**索引设计:**

- 主键索引: `id`
- 用户查询索引: `userId + createdAt`
- 状态筛选索引: `userId + status`
- 类型筛选索引: `userId + type`

### 5.2 ContentVersion（内容版本）

存储内容的每个版本详情，支持版本对比和回滚。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `id` | string (UUID) | 是 | 版本唯一标识 |
| `contentId` | string (UUID) | 是 | 关联的内容ID（外键关联 ContentPiece.id） |
| `version` | integer | 是 | 版本号，自增 |
| `content` | text | 是 | 版本正文内容 |
| `style` | string | 否 | 文案风格标识 |
| `wordCount` | integer | 是 | 字数统计 |
| `changeNote` | string | 否 | 版本变更说明 |
| `createdAt` | datetime | 是 | 版本创建时间 |

**索引设计:**

- 主键索引: `id`
- 版本查询索引: `contentId + version`（唯一索引）
- 时间排序索引: `contentId + createdAt`

### 5.3 CollabSpace（协作空间）

管理团队协作空间的基本信息。

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `id` | string (UUID) | 是 | 空间唯一标识 |
| `name` | string | 是 | 空间名称，最大长度100字符 |
| `description` | string | 否 | 空间描述，最大长度500字符 |
| `ownerId` | string (UUID) | 是 | 空间所有者用户ID |
| `memberCount` | integer | 是 | 成员数量 |
| `contentCount` | integer | 是 | 空间内内容数量 |
| `status` | enum | 是 | 空间状态：`active` / `archived` / `deleted` |
| `createdAt` | datetime | 是 | 创建时间 |

**索引设计:**

- 主键索引: `id`
- 所有者查询索引: `ownerId`
- 成员查询索引: 通过关联表 `space_members` 实现

## 6. 技术实现方案

### 6.1 AI 通道选择策略

工匠AI 采用**多模型路由**策略，根据不同的内容创作场景选择最优的 AI 模型：

| 创作场景 | 首选模型 | 备选模型 | 选择依据 |
|---------|---------|---------|---------|
| 营销文案 | GPT-4o | Claude 3.5 | 创意能力强，中文表达自然 |
| 社交媒体内容 | GPT-4o-mini | 通义千问 | 成本低，响应快，适合批量生成 |
| 短视频脚本 | Claude 3.5 | GPT-4o | 结构化输出能力强，逻辑清晰 |
| 产品描述 | GPT-4o | 文心一言 | SEO 理解能力好，关键词布局精准 |
| 品牌故事 | Claude 3.5 | GPT-4o | 长文本叙事能力优秀，情感表达细腻 |

**模型路由规则:**

```
function selectModel(request):
    if request.type == 'video_script':
        return 'claude-3.5-sonnet'  // 结构化脚本首选
    if request.type == 'brand_story':
        return 'claude-3.5-sonnet'  // 长文本叙事首选
    if request.type == 'social_media' and request.batch == true:
        return 'gpt-4o-mini'        // 批量生成用轻量模型
    if request.type == 'product_description':
        return 'gpt-4o'             // SEO优化首选
    return 'gpt-4o'                 // 默认使用GPT-4o
```

### 6.4 AI Prompt 工程方案

```
系统角色设定:

- 产品名称: {productName}

目标受众: {targetAudience}
字数要求: {minWordCount}-{maxWordCount}字
关键词要求: 请自然融入以下关键词 - {keywords}

输出要求:
1. 每套文案需包含标题和正文
2. 标题需具有吸引力，能引发点击欲望
3. 正文需逻辑清晰，层层递进

```

### 6.5 集成方案

#### 与平台其他模块的集成

- **用户中心集成**: 通过统一的用户认证服务（OAuth2.0 / JWT）进行身份验证，获取用户基本信息和使用权限
- **数据中台集成**: 内容创作数据同步至数据中台，支持跨模块的数据分析和用户画像构建
- **通知服务集成**: 任务分配、审核通知通过统一消息中心推送（站内信、邮件、企业微信）
- **文件存储集成**: 导出的 PDF/Word 文件存储至统一对象存储服务（OSS/S3）
- **管家AI集成**: 用户可通过管家AI直接调用工匠AI的内容生成能力（如"帮我写一篇小红书笔记"）

#### 第三方服务集成

| 服务 | 用途 | 集成方式 |
|------|------|---------|
| OpenAI API | GPT-4o / GPT-4o-mini 模型调用 | REST API + SDK |
| Anthropic API | Claude 3.5 模型调用 | REST API + SDK |
| 阿里云百炼 | 通义千问模型调用 | REST API |
| Redis | 内容缓存、生成任务队列 | Redis Client |
| PostgreSQL | 核心数据持久化存储 | ORM (MyBatis-Plus / Prisma) |
| Elasticsearch | 内容全文检索 | REST API |
| MinIO / OSS | 文件存储（导出文件、参考素材） | S3 兼容 API |

### 6.6 性能优化策略

- **AI 生成缓存**: 相同输入参数的生成请求命中缓存，避免重复调用 AI 模型
- **流式输出**: 采用 SSE（Server-Sent Events）实现 AI 生成内容的流式输出，提升用户等待体验
- **异步任务队列**: 批量生成任务通过消息队列（RabbitMQ / Kafka）异步处理
- **数据库读写分离**: 内容查询走从库，写入走主库，提升并发读取性能
- **CDN 加速**: 静态资源（编辑器组件、模板文件）通过 CDN 分发

### 6.7 安全策略

- **内容安全审核**: 生成内容经过敏感词过滤和合规性检查，确保内容安全
- **用户数据隔离**: 严格的数据权限控制，用户只能访问自己的内容和已加入的协作空间
- **API 限流**: 基于 Token Bucket 算法的 API 限流，防止滥用
- **Prompt 注入防护**: 对用户输入进行清洗和转义，防止 Prompt 注入攻击
- **操作审计**: 关键操作（内容删除、空间解散）记录审计日志
