## 1. 角色定位

### 1.1 产品定位

探路者 AI（Scout）是 AI Mate 平台中的**投资对接专家**，专注于帮助创业者、中小企业主及融资负责人高效发现投资商、投资机构与融资机会。通过 AI 驱动的智能搜索、精准推荐与深度分析能力，Scout 将传统的融资对接流程从"人工筛选、逐一联系"升级为"智能匹配、一键触达"，大幅降低融资拓展的时间成本与试错风险。

### 1.2 目标用户

| 用户类型 | 典型场景 | 核心诉求 |
|---------|---------|---------|
| **初创企业创始人** | 寻找天使投资、种子轮融资 | 快速找到靠谱投资方，降低融资成本 |
| **融资经理/CFO** | 投资商筛选、对比投资条件、资质审核 | 高效筛选、多维度对比、数据支撑决策 |
| **业务拓展人员** | 寻找战略合作、行业资源对接 | 精准匹配、快速建立联系 |
| **市场分析师** | 行业调研、投资趋势洞察 | 结构化数据、趋势分析报告 |
| **自由创业者** | 找融资、找投资、评估市场 | 低门槛获取专业级投资分析 |

### 1.3 核心价值

- **效率提升**：将传统融资对接周期从数周缩短至数小时，AI 智能搜索替代人工筛选。
- **精准匹配**：基于行业、需求、融资规模等多维度进行智能推荐，匹配准确率目标 > 85%。
- **数据驱动**：提供结构化的投资行情分析与投资商对比报告，辅助科学决策。
- **知识沉淀**：行业报告库持续积累，形成可复用的商业知识资产。
- **成本节约**：通过智能对比投资条件与资质预筛，减少无效沟通与试错成本。

### 1.4 与其他 AI 角色的协作关系

```
用户 → Scout（发现资源）→ Sage（制定策略）→ 执行落地
         ↓
    发现投资商/合作伙伴
    分析投资行情
    生成投资商对比报告
```

Scout 侧重于"发现"与"分析"，为 Sage（军师）的策略制定提供数据基础。用户可将在 Scout 中获取的投资商分析结果一键传递至 Sage，用于生成融资策略与商业计划。

## 2. 核心功能

### 2.1 投资商搜索

#### 功能概述

提供基于关键词与分类的智能投资商搜索能力，支持多维度筛选（地区、投资规模、资质等级等），并利用 AI 语义理解实现模糊匹配与智能排序。

#### 功能详情

**搜索方式**：
- **关键词搜索**：输入投资机构名称、投资阶段、投资领域等关键词，AI 进行语义理解与模糊匹配。
- **分类浏览**：按投资类型（如天使投资、VC、PE、战略投资等）逐级浏览，支持多级分类筛选。
- **智能联想**：输入过程中实时展示搜索建议与热门搜索词。

**筛选维度**：
- **地区筛选**：省/市/区三级地区选择，支持多选。
- **投资规模**：自定义投资金额区间滑块，支持按最低投资额、投资阶段等维度筛选。
- **资质等级**：基金牌照、AUM 规模、投资阶段偏好等多维度资质筛选。
- **合作状态**：可合作/已合作/已暂停等状态筛选。
- **评分排序**：按用户评分、合作次数、响应速度等排序。

**AI 增强能力**：
- **语义扩展**：将用户输入的自然语言描述转化为结构化搜索条件。例如"找一家江浙沪地区、投资规模在 500 万到 2000 万之间的天使投资机构"自动解析为地区=江浙沪、投资类型=天使投资、投资金额=500万-2000万的筛选条件。
- **智能排序**：综合匹配度、投资商活跃度、历史合作评价等多因子进行个性化排序。
- **搜索结果摘要**：对搜索结果进行 AI 摘要，快速呈现核心信息。

#### 输入输出

| 项目 | 说明 |
|-----|------|
| 输入 | 关键词/分类选择 + 筛选条件 + 排序偏好 |
| 输出 | 投资商列表（卡片式展示）+ AI 搜索摘要 + 筛选标签统计 |

### 2.2 合作伙伴推荐

#### 功能概述

基于用户的行业背景、业务需求与历史行为，AI 智能推荐潜在的合作伙伴，包括渠道合作、技术合作、投资对接等多种合作类型。

#### 功能详情

**推荐机制**：
- **行业匹配度分析**：分析用户所在行业与潜在合作伙伴的行业关联度，计算匹配分数。
- **需求互补分析**：基于用户发布的合作需求（如"需要电商运营团队"），推荐具备相应能力的合作伙伴。
- **历史行为学习**：根据用户的浏览、收藏、联系等行为，持续优化推荐算法。
- **社交网络分析**：分析已有合作关系的网络图谱，发现潜在的二度连接机会。

**推荐类型**：
- **渠道合作**：推荐销售渠道、分销商、代理商等。
- **技术合作**：推荐技术合作伙伴、研发伙伴、技术顾问等。
- **投资对接**：推荐匹配的投资机构、天使投资人等。
- **跨界合作**：发现跨行业的创新合作机会。

**交互方式**：
- **推荐卡片**：每个推荐以卡片形式展示，包含匹配度评分、合作类型标签、简要介绍。
- **反馈机制**：用户可对推荐结果进行"感兴趣/不感兴趣"反馈，持续优化推荐精度。
- **批量操作**：支持批量收藏、批量导出推荐结果。

### 2.3 市场行情分析

#### 功能概述

提供行业投资趋势的实时分析与可视化展示，帮助用户快速了解目标市场的投融资状况、估值走势、竞争格局等关键信息。

#### 功能详情

**分析维度**：
- **估值趋势**：展示特定行业/阶段的历史估值走势图，支持按周/月/季度切换。
- **供需指数**：基于融资需求量、投资活跃度、成交金额等数据计算供需指数，判断市场热度。
- **区域分布**：以热力图形式展示投资商/融资需求方的地域分布情况。
- **竞争态势**：分析目标市场的竞争密度、头部机构市占率等。

**AI 分析能力**：
- **趋势预测**：基于历史数据进行短期趋势预测，标注关键拐点与异常波动。
- **异常检测**：自动识别估值异常波动、供需失衡等市场信号，及时预警。
- **归因分析**：对市场变化进行多因子归因分析，解释变化背后的驱动因素。

**输出格式**：
- **可视化图表**：折线图、柱状图、热力图、饼图等多种图表类型。
- **结构化报告**：AI 生成文字分析报告，包含关键发现、趋势判断与操作建议。
- **数据导出**：支持导出为 Excel/PDF 格式，便于离线使用与汇报。

### 2.4 行业报告查询

#### 功能概述

提供行业研究报告的知识库检索与 AI 摘要功能，帮助用户快速获取行业洞察，无需阅读冗长的完整报告。

#### 功能详情

**知识库构成**：
- **公开报告**：整合来自行业协会、研究机构、咨询公司的公开报告。
- **平台报告**：AI Mate 平台基于用户数据生成的行业洞察报告。
- **用户贡献**：经过审核的用户投稿报告与案例分析。

**检索方式**：
- **全文搜索**：支持对报告标题、摘要、正文内容的全文检索。
- **分类浏览**：按行业、报告类型（市场报告、技术报告、政策解读等）、发布时间分类浏览。
- **AI 问答**：用户可直接向 AI 提问，AI 从知识库中检索相关内容并生成回答。

**AI 摘要能力**：
- **一键摘要**：对选定的报告生成结构化摘要，包含核心观点、关键数据、趋势判断。
- **多报告对比**：选取多份报告进行交叉对比，提炼共识观点与分歧点。
- **智能引用**：AI 回答中标注信息来源，支持跳转至原文对应段落。

### 2.5 资源对比分析

#### 功能概述

支持用户选取多个投资商/合作伙伴进行多维度对比分析，以结构化表格形式呈现差异，辅助决策。

#### 功能详情

**对比维度**：
- **基础信息**：名称、地区、成立时间、机构规模。
- **投资方向**：投资阶段偏好、投资领域、投资案例。
- **投资条件**：投资金额区间、最低投资额、投资决策周期。
- **资质认证**：基金牌照、AUM 规模、投资阶段偏好。
- **服务评价**：用户评分、合作次数、响应速度、投后评价。
- **投资决策效率**：投资决策周期、可投资金额、投资地域覆盖。

**AI 分析能力**：
- **优劣势分析**：AI 自动识别每个资源的核心优势与潜在风险。
- **综合评分**：基于用户偏好权重，计算各资源的综合加权评分。
- **推荐结论**：AI 给出推荐结论与选择建议，说明推荐理由。

**交互方式**：
- **勾选对比**：在搜索结果列表中勾选 2-5 个资源进入对比模式。
- **维度自定义**：用户可自定义对比维度与权重。
- **报告导出**：生成对比分析报告，支持分享与导出。

### 6.1 AI 通道选型

| 能力模块 | AI 通道 | 选型理由 |
|---------|--------|---------|
| **语义搜索** | Embedding + Vector Search | 将投资商信息与用户查询向量化，实现语义级别的匹配检索 |

| **市场分析** | LLM + Data Analysis | LLM 解读数据趋势，生成自然语言分析报告 |
| **报告摘要** | LLM（长上下文） | 利用长上下文窗口处理完整报告，生成结构化摘要 |
| **对比分析** | LLM + Rule Engine | 规则引擎计算量化评分，LLM 生成定性分析与建议 |

### 6.3 关键技术方案

#### 6.3.1 AI 智能搜索实现

**搜索流程**：

1. **意图解析**：用户输入自然语言查询，LLM 将其解析为结构化搜索条件（关键词、地区、投资金额偏好、资质要求等）。
2. **向量检索**：将查询文本通过 Embedding 模型转为向量，在 Vector DB 中进行相似度检索，召回 Top-K 候选。
3. **结构化过滤**：基于解析出的结构化条件，在 PostgreSQL 中进行精确过滤。
4. **融合排序**：将向量检索结果与结构化过滤结果融合，综合考虑语义相似度、业务匹配度、投资商质量等因子进行排序。
5. **摘要生成**：LLM 对搜索结果生成自然语言摘要，帮助用户快速了解搜索概况。

**技术要点**：
- Embedding 模型选择：推荐使用 `text-embedding-3-large` 或开源的 `bge-large-zh-v1.5`（中文优化）。
- 向量数据库选择：推荐 Milvus 或 Qdrant，支持高性能 ANN 检索。
- 搜索结果缓存：利用 Redis 缓存热门查询结果，设置 TTL 为 5 分钟。

#### 6.3.2 合作伙伴推荐实现

**推荐算法**：

```
综合匹配分 = W1 * 行业匹配度 + W2 * 需求互补度 + W3 * 历史成功率 + W4 * 活跃度

其中：
- 行业匹配度：基于行业分类体系计算（精确匹配=1.0，同大类=0.7，相关行业=0.4）
- 需求互补度：基于需求标签的 Jaccard 相似度计算
- 历史成功率：基于历史推荐反馈的点击率与转化率
- 活跃度：基于最近登录时间、响应速度等行为指标
- 默认权重：W1=0.35, W2=0.30, W3=0.20, W4=0.15
```

**冷启动策略**：
- 新用户：基于行业分类与注册信息进行粗粒度推荐。
- 新投资商：给予曝光加权，快速积累评价数据。

#### 6.3.3 市场行情分析实现

**数据采集**：
- 内部数据：平台搜索量、融资需求量、成交金额等业务数据。
- 外部数据：对接第三方行业数据 API（如国家统计局、行业协会数据）。
- 数据更新频率：核心指标每日更新，趋势数据每周汇总。

**AI 分析流程**：
1. 数据预处理：清洗、聚合、计算衍生指标。
2. 异常检测：基于统计方法（Z-Score、IQR）识别异常数据点。
3. 趋势分析：LLM 结合数据图表进行趋势解读，生成分析文本。
4. 归因分析：多因子回归分析，LLM 生成自然语言归因报告。

- **数据脱敏**：投资商联系方式在列表接口中脱敏展示（如 138\*\*\*\*5678），仅在用户发起联系请求后完整展示。
- **权限控制**：投资商创建/编辑仅限创建者本人和管理员；搜索与查看对所有登录用户开放。
- **频率限制**：AI 搜索接口限制每用户每分钟 10 次；AI 分析接口限制每用户每小时 5 次。
- **审计日志**：所有数据变更操作记录审计日志，保留 90 天。
